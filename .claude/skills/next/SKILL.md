name: next
description: 给出下一个任务卡：从 5 周计划里挑出用户接下来该做的一小步，拆成 1 到 3 小时能完成的任务。
disable-model-invocation: true
---

1. 读 `docs/progress.md` 看已完成什么；需要时用 docs 工具读 CLAUDE.md 里链接的计划文档。
2. 看一眼仓库当前代码状态（`git log --oneline -10`、相关目录），确认进度记录是真的。
3. 挑出下一个最小可交付步骤，输出一张任务卡，不写任何业务代码：

```
## 任务：<一句话>
**为什么做这个**：它在整体架构里的位置（1 到 2 句）
**你要学会的概念**：……（每个配一个官方文档链接）
**要改/新建的文件**：……
**步骤**：1. … 2. … 3. …（描述做什么，不给代码）
**完成标准**：一条能跑的命令或测试，跑通就算完成
**常见坑**：2 到 3 条
**面试可能问**：1 到 2 个问题
```

4. 需要新依赖时，告诉用户运行哪条 `uv add` 命令，让用户自己装。
