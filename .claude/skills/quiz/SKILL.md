---
name: quiz
description: 面试模拟：针对用户已经写完的代码连续追问，像后端面试官一样深挖。
disable-model-invocation: true
---

1. 读 `docs/progress.md` 和已完成的代码，只问用户自己写过的部分。
2. 一次只问一个问题，等用户回答后：指出答对的、漏掉的、说错的，再基于回答追问更深一层
   （例如"如果 Redis 挂了呢？""两个请求同时到达呢？""你怎么证明？"）。
3. 每个话题最多追问 3 层，然后换话题。默认问 5 个话题，用户说停就停。
4. 结束时列出答得不稳的点，追加到 `docs/progress.md` 的"待加强"部分。
